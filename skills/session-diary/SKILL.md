# session-diary: 자동 세션 일기

사람이 부르는 스킬이 아니다. 한 번 켜면 스크립트가 알아서 일기를 쓴다. 이 스킬은 켜고 끄고, 상태를 보고, 쓰인 일기를 읽어 주는 일만 한다. 일기를 쓰는 규칙은 `references/write.md`, 관찰 기준과 근거는 `references/observe.md`, 기록 형식은 `references/claude.md`, `references/codex.md`에 있다.

아래 `<스킬>`은 이 스킬 폴더의 절대 경로다. 일기는 `~/.session-diary/<날짜>.md`에 있다. 지금은 macOS에서만 자동 실행을 켤 수 있다.

## 켜기
켜기 전에 한 번 알리고 확인을 받는다. 시키지 않았는데 켜지 않는다.
- 매 정각과 로그인 때 깨어나, 전날까지 빠진 일기가 있으면 쓴다. 자정이 지나면 전날 일기가 써진다.
- 이 컴퓨터의 모든 프로젝트 대화를 읽어 AI에 보낸다. 대화가 있던 날마다 AI 호출에 사용량이 든다.
- 켠 날의 어제부터 쓴다. 그 전 날짜는 쓰지 않는다.

```bash
python3 <스킬>/scripts/diary_auto.py on
```
결과를 그대로 전한다. 플러그인을 업데이트한 뒤 새 판을 쓰려면 다시 켠다.

## 끄기
```bash
python3 <스킬>/scripts/diary_auto.py off
```
자동 실행만 멈춘다. 쓴 일기는 지우지 않는다.

## 상태 보기
```bash
python3 <스킬>/scripts/diary_auto.py status
```
켜짐 여부, 빠진 날짜, 쓰지 못한 날짜, 최근 실행 기록을 전한다.

## 일기 읽어 주기
해당 날짜의 일기 파일을 읽어 오늘 한 줄, 바꿀 행동, 내일의 계획을 짧게 전하고 위치를 알려 준다. 일기 전체를 대화에 붙이지 않는다. 일기 끝의 "내 메모" 칸에 쓴 글은 다음 일기가 읽고 답한다고 알려 준다.

## 다시 쓰기
지난 날짜를 다시 쓰고 싶다고 하면, "내 메모" 칸에 쓴 내용이 사라진다고 알리고 확인을 받은 뒤 부른다. 오늘 날짜는 하루가 끝나야 쓸 수 있다.
```bash
python3 <스킬>/scripts/diary_auto.py write --date <날짜> --force
```

## 하지 않는 것
- 시키지 않았는데 켜거나 끄기.
- 일기 내용을 공개 저장소, 기억 파일, 설정 파일로 옮기기. 사용자가 원하면 그때 한다.
