# criteria-init: 기준 점검 켜기

켜면 두 가지가 함께 돈다.
- **훅**: 사용자가 일을 맡기는 요청(필터해줘, 기획해줘 등)을 보낼 때 기록소를 조회해, 확정 기준을 Claude에게 알려 준다.
- **점검 mod**: 턴이 끝날 때마다 그 턴을 판정 모델이 보고, 사용자 생각에 빈 곳이 보이면 입력창 위에 질문 하나를 띄운다. 보는 것은 생략된 전제, 섞인 구분, 원리를 이해했다면 답할 수 있는 질문, 빠진 판단 기준이다. 답은 보기를 누르거나(객관식) 직접 써서(주관식) 하고, "모름"과 "건너뛰기"도 있다. 답은 대화로 들어가 Claude가 이어서 다룬다.

**둘 다 `hack-users-for-llms` 플러그인에 들어 있고 기본은 꺼져 있다.** 이 스킬은 스위치(설정 파일)만 바꾼다. 사용자의 `settings.json`은 건드리지 않는다.

## 전제
- 훅과 점검 mod는 **Claude Code에 플러그인으로 설치한 경우에만** 동작한다. Codex나 폴더 링크로 설치한 경우 설정 파일은 써지지만 둘 다 동작하지 않는다. 이 경우 그렇게 알린다.
- 점검 mod는 mod를 지원하는 Claude Code에서만 돈다. 모바일 앱에는 입력칸이 없어 보기와 "모름"만 보인다.
- 플러그인을 방금 설치하거나 업데이트했다면 새 세션을 시작해야 적용된다. 설정 파일을 바꾸는 것은 재시작 없이 다음 턴부터 반영된다.

## 설정 파일
`<기록소 폴더>/config.json`. 프로젝트(`.criteria/`)에 있으면 그것이, 없으면 전역(`~/.criteria/`)의 것이 쓰인다. 프로젝트 설정이 전역보다 우선한다.

```json
{ "hook": { "enabled": true, "intensity": "light", "max_per_session": 3, "cooldown_turns": 3 } }
```

| 키 | 기본 | 뜻 |
|---|---|---|
| `enabled` | `false` | `true`일 때만 동작 |
| `intensity` | `light` | `light`: 훅은 위임 요청이면서 신호(세션 첫 위임, 방향을 바꾸는 결정, 긴 산출물)가 있을 때만, 점검 mod는 답이 없으면 작업이 틀어질 것이 분명할 때만 묻는다. `active`: 훅은 위임 요청이면 항상, 점검 mod는 빈 곳이 분명히 보이면 묻는다 |
| `max_per_session` | `3` | 점검 mod가 세션당 묻는 최대 횟수. 확정 기준을 알려 주는 훅은 이 한도와 무관 |
| `cooldown_turns` | `3` | 점검 mod가 물은 뒤 최소 몇 턴을 쉬고 다시 물을지 |

## 켜기 (init)
한 번에 하나씩 묻는다.
1. **범위**: 이 프로젝트만(기본) / 모든 프로젝트(전역).
2. **강도**: `light`(기본) / `active`. 각각이 무엇인지 한 줄씩 설명한다.
3. 설정 파일을 쓴다. 이미 있으면 읽어서 `hook` 키만 바꾸고 다른 내용은 그대로 둔다. 기록소 폴더가 없으면 만든다.
4. 프로젝트가 git이면 `.criteria/`를 `.gitignore`에 넣을지 묻는다. 개인 기준이 repo에 올라갈 수 있다. 동의 없이 파일을 고치지 않는다.
5. 결과를 알린다: 어디에 어떤 설정으로 켰는지, 훅이 하는 일(위임 요청일 때만 기록소를 조회), 점검 mod가 하는 일(턴이 끝난 뒤 입력창 위에서 세션당 최대 N번 묻기, 판정에 턴마다 작은 모델 호출이 든다), 끄는 방법.

## 끄기
설정 파일의 `enabled`를 `false`로 바꾼다. 파일을 지우지 않는다. 프로젝트 설정이 전역을 덮어쓰므로, 전역은 켜 두고 특정 프로젝트만 끄는 것도 이 방식으로 된다.

## 상태 보기
프로젝트와 전역의 설정 파일을 읽어 지금 이 위치에서 실제로 적용되는 값(켜짐 여부, 강도, 한도)과 어느 파일에서 왔는지 보여준다. 세션 안에서 점검 mod가 이미 몇 번 물었는지는 알 수 없다.

## 하지 않는 것
- 사용자가 켜 달라고 하지 않았는데 켜지 않는다.
- 강도와 범위를 묻지 않고 임의로 정하지 않는다.
- `settings.json`이나 훅 설정을 직접 고치지 않는다.
